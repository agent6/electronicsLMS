# UI UX Quality Bar

## Feature Completion Standard

A feature is complete only when the happy path, empty state, loading state, error state, validation, permissions, mobile layout, desktop layout, and navigation behavior all work.

## Visual Standard

- Modern maker lab feel.
- Polished but not decorative for its own sake.
- Hardware, code, and progress are the visual center.
- Cards are used for repeated items, not nested page sections.
- Buttons use clear labels or familiar icons.
- Text fits within controls at mobile and desktop sizes.
- Color is useful for meaning, progress, warning, and state.

## Interaction Standard

- Every button does something real.
- Every link goes somewhere useful.
- Forms preserve input on validation errors.
- Save actions provide clear success/error feedback.
- HTMX updates never leave the page in an ambiguous state.
- Keyboard users can reach all controls.

## Copy Standard

- Student-facing copy is concrete and energetic.
- Instructions are direct.
- Safety warnings are impossible to miss.
- Error messages say what happened and what to try next.

## Accessibility Standard

Target WCAG AA: semantic structure, labels, contrast, focus states, keyboard navigation, reduced motion, and screen-reader-friendly status messages.
