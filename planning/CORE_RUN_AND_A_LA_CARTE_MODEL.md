# Core Run and A la Carte Model

## Core Run

The Core Run is a recommended 21-stop learning path. It is not a lock, not a calendar requirement, and not a source of punishment. Students can open any published tutorial they are ready to try.

## A la Carte

A la Carte is the full published project library. Students use it to follow curiosity by part, skill, difficulty, time, and project type. It should feel like a maker menu, not homework.

## Availability

Only published tutorials appear in student UI. Hidden tutorials stay internal until authored and checked.

## Progress

Core Run progress shows completed stops only when the referenced tutorials exist and the student completes them. A la Carte progress tracks completed published tutorials, remixes, Dev Logs, and public project writeups.

## Completion

Completion is based on self-check and private Dev Log. No public sharing is required to complete any learning path.

## Transition to Independent Projects

As students finish more skill areas, the product recommends student-choice inventions. Student-choice projects use parts the student already knows, a short plan, debugging notes, and a public text writeup when the student chooses to publish.
