# Lesson Template

## Required Lesson Sections

1. Hook: one student-facing sentence that makes the project feel concrete.
2. What You Will Build: short description of the finished behavior.
3. What You Will Learn: 3-5 concepts, written plainly.
4. Parts Needed: exact parts, equivalent acceptable parts, and kit source when known.
5. Safety Notes: voltage, current, moving parts, heat, light, battery, water, and sensor-specific warnings.
6. Before You Power It: wiring checks and polarity checks.
7. Wiring Overview: original diagram area and text description.
8. Step-by-Step Build: small sections that add one idea at a time.
9. Code Section: planned area for future original MicroPython code.
10. What Just Happened: explanation in student language.
11. Common Bugs and Fixes: symptom-driven debugging.
12. Checkpoint: self-check statement for completion.
13. Dev Log Prompt: short private reflection.
14. Remix Challenge: one small creative extension.
15. Next Suggestions: published lessons only.
16. References: external links used for inspiration or hardware documentation.

## Completion Rule

A lesson is complete when the student marks the checkpoint and writes a private Dev Log. Hardware verification is self-reported. No quiz is required.

## Publishing Rule

Lesson Dev Logs are private. Public project writeups are separate artifacts and require verified email.
