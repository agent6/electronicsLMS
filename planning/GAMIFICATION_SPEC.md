# Gamification Spec

## Goals

Gamification should reward progress, persistence, debugging, and creative building without turning learning into speed competition. It should be visible enough to motivate and quiet enough that the project remains the point.

## XP

XP is lightweight. It confirms meaningful actions:

- Complete a tutorial checkpoint.
- Write a private Dev Log.
- Complete a Core Run stop.
- Finish a remix.
- Publish a text project writeup after verification.
- Return after a break and make meaningful progress.
- Complete a student-choice invention step.

XP does not unlock hidden lessons. Published content is available based on content readiness, not student level.

## Badges

Only earnable badges appear. Badges map to real actions in published content, such as First Blink, Setup Complete, Breadboard Rookie, Analog Explorer, PWM Builder, Button Boss, Display Builder, Motor Mover, RFID Ranger, Motion Mapper, NeoPixel Artist, IoT Explorer, Debugging Hero, Remix Maker, and Invention Shipper.

## Momentum

Momentum measures meaningful sessions. A session counts when a student completes a tutorial, writes a Dev Log, updates a project, finishes a remix, or returns to fix a problem. Momentum is not a daily streak and does not reset identity or progress after missed days.

## Project Passport

The passport is a visual record of completed Core Run stops and skill areas. It must show only real completed work. Hidden or unauthored stops are not shown as active tasks.

## Anti-Patterns

Do not build leaderboards, speed rankings, fake locked badges, fake streaks, fake notifications, or punishment mechanics.
