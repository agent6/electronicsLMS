# Curriculum Roadmap

## Curriculum Model

The curriculum moves from setup to blink, then through inputs, outputs, sensors, displays, movement, wireless projects, cleaner code, mini projects, and student-choice inventions. Every lesson is original ObsoleteHQ content. External sources can be linked as references, including SunFounder documentation, but text, code, diagrams, and explanations must be written for ObsoleteHQ.

## Core Run Map

The Core Run is a recommended 21-stop path, not a lock. Students may work on any published lesson in any order. Hidden lessons are not shown in product UI.
