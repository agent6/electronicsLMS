# ObsoleteHQ Planning Package

ObsoleteHQ is a teen-focused electronics learning platform for students ages 13-17. Students learn MicroPython, Raspberry Pi Pico 2 W, circuits, sensors, displays, motion, wireless projects, and independent project design by building real hardware.

Domain: `obsoletehq.com`

This repository currently contains planning documents only. It does not contain application code, generated tutorials, Docker configuration, database schema, UI components, or deployment files.

## Product Shape

- One brand: ObsoleteHQ.
- One audience: teen students.
- Learning model: start with blink, add one concept at a time, and keep building toward independent inventions.
- Recommended hardware: SunFounder Raspberry Pi Pico 2 W Ultimate Starter Kit and 37-in-1 Sensor Module Starter Kit.
- Hardware policy: lessons specify required parts so students may source equivalents.
- Curriculum policy: ObsoleteHQ lessons must be original writing, original diagrams, original code, and original debugging help.
- Source reference policy: cite useful references, including [https://docs.sunfounder.com/projects/pico-2w-kit/en/latest/](https://docs.sunfounder.com/projects/pico-2w-kit/en/latest/) and [https://docs.sunfounder.com/projects/pico-2w-kit/en/latest/pyproject/for_micropython_user.html](https://docs.sunfounder.com/projects/pico-2w-kit/en/latest/pyproject/for_micropython_user.html), without copying proprietary content.
